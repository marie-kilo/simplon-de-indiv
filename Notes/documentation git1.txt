		{Ton projet local = ton ordinateur}
		{Ton remote = GitHub}
git remote  	(# Voir les remotes configurés) il me donne : origin (Ton projet local est connecté à un dépôt GitHub nommé origin.)

git remote -v   (Voir les URL des remotes):==>	origin  https://github.com/marie-kilo/mon-projet.git (fetch)
					   ==>	origin  https://github.com/marie-kilo/mon-projet.git (push)
						
{fetch = d’où Git récupère les mises à jour}
{push = où Git envoie ton code}

git remote add orgigin "le lien vers le dossier sur mon github"   (Ajouter un remote)
==>git remote add origin https://github.com/marie-kilo/mon-projet.git

{Ça signifie :

“Git, connecte ce dossier local à ce dépôt GitHub.”}


git push -u origin main			(git push= Envoie mes commits vers GitHub)
					(-u signifie set upstream.👉 Tu dis à Git :
					“À partir de maintenant, ma branche locale main est liée à origin/main sur GitHub.”)
					(origin= C’est le nom du remote, c’est‑à‑dire le dépôt GitHub auquel ton projet local est connecté.)
					(main = C’est la branche que tu veux envoyer) il ya aussi (main , master , dev , feature/login ...)
